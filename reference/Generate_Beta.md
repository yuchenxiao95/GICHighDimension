# Generate Sparse Coefficient Vector

Creates a sparse coefficient vector with a specified pattern of non-zero
values for use in simulation studies, such as benchmarking variable
selection methods.

## Usage

``` r
Generate_Beta(P, k, type = 1)
```

## Arguments

- P:

  Integer. Total number of predictors (must be a positive integer).

- k:

  Integer. Number of non-zero coefficients (must be between 1 and `P`).

- type:

  Integer. Pattern type for non-zero coefficients:

  - `1`: Equally spaced non-zero values

  - `2`: First `k` positions are non-zero

  - `3`: Decaying values from 10 to 0.5

## Value

A list with components:

- `beta`:

  A numeric vector of length `P` with the specified sparsity pattern.

- `indices`:

  An integer vector of indices where `beta` is non-zero.
